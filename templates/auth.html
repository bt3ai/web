Schwab Authentication

Follow these steps to authenticate with your Schwab account

1

Click the Authentication Link

Click the button below to open the Schwab authentication page in a new tab.

Open Schwab Auth Page
2

Complete Authentication

In the new tab, complete the Schwab authentication process. You'll be redirected to a URL that contains an authorization code.

Note: The redirect URL will contain your authorization code. Copy the entire URL from your browser's address bar.
3

Copy the Returned URL

After authentication, copy the URL from your browser's address bar and paste it below:

Important: Make sure to copy the entire URL, including the "code=" parameter.
4

Return to Main Application

Go back to the main application window and paste the copied URL to complete the authentication process.

Need Help?
  • Make sure you're logged into your Schwab account
  • The authorization code is only valid for a short time
  • If you encounter issues, try refreshing the auth page
  • Contact support if authentication continues to fail
